# BUG-003 — [MOB] Push notifications show previous baby's name and age after updating Baby Profile

[← Bug Reports](README.md)

**Source:** Exploratory / core-app testing (not part of the Subscription Test Plan)
**Also tracked as:** [Issue #2](https://github.com/aysuismayil/YumYum-Mobile-Nutrition-App-QA/issues/2)
**Regression test case:** [TC-REG-002](../test-cases/regression-test-cases.md)

## Environment

| Field | Value |
|---|---|
| App version and build | 5.3.2 (1) |
| Device and iOS version | iPhone 16 Pro, iOS 26.6.1 |

## Steps to Reproduce

1. Open the app.
2. Open Baby Profile.
3. Observe the current baby name and DOB.
4. Edit the baby's name and DOB.
5. Save the changes.
6. Receive the push notification.
7. Observe that the push notification still shows the previous baby's name and age.

## Actual Result

If User updates baby's name and DOB, push notifications still show the previous baby's name and age.

## Expected Result

Push notifications should show the updated baby's name and age after Baby Profile is updated.
