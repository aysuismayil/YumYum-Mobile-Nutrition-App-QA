## Environment

| Field | Value |
|---|---|
| App version and build | 5.3.2 (1) |
| Device and iOS version | iPhone 16 Pro, iOS 26.6.1 |
| Device language | en-US |

## Steps to Reproduce

1. Open the app
2. Make sure User is enrolled in the 7-Day Challenge
3. Log a food before 9 AM
4. Make sure the current Challenge day is completed
5. Wait until 9 AM
6. Observe the push notification

## Actual Result

If User logs a food for the 7-Day Challenge before 9 AM, the Challenge push notification is still received at 9 AM asking User to log a food.

## Expected Result

The Challenge push notification shouldn't be received at 9 AM if User already logged a food for the current Challenge day.
