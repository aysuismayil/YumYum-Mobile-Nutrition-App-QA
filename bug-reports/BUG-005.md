# BUG-005 — [7-Day Challenge] The Challenge is reversed to "Start 7 days challenge" after User logs out and logs back in

| Field | Value |

## Steps to Reproduce

1. Launch an App
2. Make sure User is enrolled in the 7-Day Challenge and the Challenge shows Day 1 of 7.
3. Log out
4. Log back in with the same account
5. Navigate to the Home tab
6. Observe the 7-Day Challenge module shows "Start 7 days challenge".
7. Kill the app.
8. Relaunch the app.
9. Observe the 7-Day Challenge module again.

## Actual Result

If User is enrolled in the 7-Day Challenge, logs out and logs back in with the same account, the 7-Day Challenge module on Home is reversed to the original Start 7 days challenge state. After User kills and relaunches the app, the Challenge shows the correct enrolled state again.

## Expected Result

The 7-Day Challenge should remain in the enrolled state after User logs out and logs back in. User should not need to kill and relaunch the app.
