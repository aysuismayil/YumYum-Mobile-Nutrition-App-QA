# BUG-001 — Unable to use remaining Free Food Logs after Premium expires

[← Bug Reports](README.md)

**Source:** Subscription feature testing
**Also tracked as:** [Issue #5](https://github.com/aysuismayil/YumYum-Mobile-Nutrition-App-QA/issues/5)
**Related rule:** Free food-log limit + return to Free after Premium expires — **Partial** support, see [gap G-1](../docs/product-overview.md#requirement-gap) (behavior of unused free food logs after Premium expires is not defined)
**Related Test Case:** [SUB - 002](../test-cases/subscription-test-cases.md#sub---002) — Free User With Partially Used Free Limits Enrolls in Subscription

## Environment

| Field | Value |
|---|---|
| App version and build | 5.3.2 |
| Device and iOS version | iPhone 16 Pro, iOS 26.6.2 |
| Account state | Free |
| Device language | en-US |

## Steps to Reproduce

1. Open the Home page using a test account with an expired Premium subscription.
2. Tap Log a Meal.
3. Select a food and tap Save Meal.
4. Verify that the Meal is successfully logged.
5. Tap Log a Food.
6. Choose a food.
7. Observe the upgrade to Premium message.

## Actual Result

The User used only 1 of 3 Free Food Logs before subscribing to Premium, but the remaining 2 Free Food Logs are not available after the Premium subscription expires. However, the User can successfully log a Meal.

## Expected Result

After Premium expires, the user should have the remaining 2 of 3 Free Food Logs available because only 1 Free Food Log was used before subscribing to Premium.
